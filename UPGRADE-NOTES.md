# Aesthetic Game Upgrade

This build updates the original portfolio without changing the core profile content.

## Added
- Four profile-based mini checkpoint games between levels.
- Locked-level flow: the next level opens after the checkpoint is cleared.
- Unique animated unlock graphic for each checkpoint.
- Profile constellation, final mission artwork, richer glass/aurora styling and section graphics.
- XP persistence through browser localStorage.
- Faster speech output (`1.12x` browser speech rate).
- Narration ends after the final mission and never auto-loops back to the beginning.
- Better focus states and reduced-motion handling.

## Level flow
1. Level 01 About → Profile Pulse → Level 02
2. Level 02 Skills → Stack Sync → Level 03
3. Level 03 Projects → Build Scanner → Level 04
4. Level 04 Journey → Journey Link → Final Mission

## Important
Browser speech speed can vary slightly depending on the device voice engine, but the requested rate is set to `1.12`.
